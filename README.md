# LoomTrace-Proto

The 2023 SC'23 workshop prototype for the LoomTrace line of work. It is a
lightweight provenance-probe toolkit for microservice meshes.

## Repository layout

```
loomtrace_proto/
  probes.py
  graph.py
experiments/
  pagerank_demo.py
```

This prototype is kept public for reference. It predates the SoCC artifact and
only implements the span-probe layer and a PageRank suspect-ranking demo.
